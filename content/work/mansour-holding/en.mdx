## Context

Mansour Holding operates Mansour Motors and related brands in Senegal. The business needed more than brochure sites: a coherent digital presence for the public, plus an internal surface where staff manage vehicle listings, media, and operational data without juggling spreadsheets.

I scoped and built a monorepo that separates public marketing from authenticated operations while sharing validators, types, and database schema.

## Problem

Before consolidation, marketing and inventory lived in disconnected tools. Public pages could not reflect stock accurately. Internal staff lacked a single dashboard with audit-friendly updates and image handling for vehicle records.

The constraint was familiar from fintech work: one operator, production expectations, and a need to ship incrementally without painting the team into a monolith they could not maintain.

## Approach

- **Monorepo with shared packages** — `shared` for Zod validators and types, `database` for Drizzle schema reference, API and web apps consuming the same contracts.
- **Split runtime** — React + Vite for the public web (Vercel), Hono API on Bun (Koyeb), Neon PostgreSQL as the system of record.
- **Auth and media** — better-auth for email/password and bearer sessions; Cloudflare R2 for vehicle imagery with typed upload flows.
- **Boring boundaries** — API owns business rules; the dashboard renders state and allowed transitions rather than encoding workflow in the UI alone.

## Outcome

The platform ships as a working monorepo: public site, API, and internal dashboard wired to the same schema. Vehicle inventory and marketing content can evolve together without duplicate data entry.

## Lessons

**Holding companies need the same discipline as fintech.** Inventory and brand surfaces look simpler than ledgers, but drift between “what the site shows” and “what ops knows” creates the same operational risk.

**Monorepos pay off when validators are shared early.** The upfront cost of packages felt heavy for a solo build; it paid back the first time a field changed on the API and TypeScript caught the dashboard gap immediately.
